\section{System Architecture Overview}
Appointly is designed as a Three-Tier Modular Monolith:
\begin{itemize}
    \item \textbf{Presentation Layer:} React + TypeScript + Vite + Tailwind CSS.
    \item \textbf{Application Layer:} Node.js + Express + TypeScript.
    \item \textbf{Data Layer:} PostgreSQL 16 + Prisma ORM with GiST exclusion constraints.
\end{itemize}
